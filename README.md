# So_long 

## Description 

First graphical project at 42 school. The project consist to create a 2D game using Minilibix (graphical library).
Learning how to manage windows, sprites and map.

The game must have one player, one or multiples collectibles. The map must be rectangular surrounded by walls and contain floor and one exit only accessible when all collectibles are collected. So, the game is finish and we can destroy the window. We can also be able to quit game with ESC key or by clicking on the red cross.

You have to check if by the starting position you can collect all collectibles and got to the exit. Now you can play !

## Instructions 

You must compile the project with `make` and run `./so_long` followed by the map. You can run this program with only one map. The map format should be .ber.
For example :
`./so_long valid_map.ber`

The project must be written in accordance to 42 Norm.
